## Часть 1. python_basics.py

### Задача 1. `count_vowels` — подсчёт гласных
```python
text = data.value
return sum(1 for ch in text.lower() if ch in VOWELS)   # VOWELS = "aeiou"
```
1. Достаём строку из контейнера `TextInput`.
2. `.lower()` приводит к нижнему регистру: по условию регистр не важен, поэтому `'A'` и `'a'`
   считаются одинаково.
3. Генераторное выражение идёт по символам; условие `ch in VOWELS` даёт `True/False`,
   а `sum(1 for ...)` прибавляет единицу за каждый символ-гласную.
4. Сложность O(n). Пустая строка даёт 0 — цикл просто не делает ни итерации.

### Задача 2. `has_unique_characters` — все символы уникальны
```python
text = data.value
return len(set(text)) == len(text)
```
1. `set(text)` — множество символов: дубликаты схлопываются в один элемент.
2. Если при построении множества ни один символ не «потерялся», длины равны → повторов нет → `True`.
3. Один проход по строке, O(n). Пустая строка: `0 == 0` → `True`.

### Задача 3. `count_one_bits` — единичные биты
```python
number = data.value
return bin(number).count("1")
```
1. `bin(number)` возвращает строку двоичной записи вида `'0b100110000'`.
2. `.count("1")` считает символы `'1'` — это и есть количество единичных битов
   (символы `'0'` и префикс `'0b'` в счёт не попадают; `'b'` — не `'1'`).
3. Альтернатива на собеседовании: `number.bit_count()` (Python 3.10+) или цикл с `n & 1` и `n >>= 1`.

### Задача 4. `multiplicative_persistence` — мультипликативная устойчивость
```python
steps = 0
while number >= 10:          # пока число двузначное или больше
    product = 1
    while number:            # перемножаем цифры текущего числа
        product *= number % 10    # % 10 берёт последнюю цифру
        number //= 10             # // 10 отбрасывает её
    number = product
    steps += 1
return steps
```
1. Внешний цикл считает «шаги»: каждый шаг заменяет число произведением его цифр.
2. Внутренний цикл извлекает цифры арифметикой: остаток от деления на 10 — последняя цифра,
   целочисленное деление на 10 её стирает.
3. Как только число стало однозначным (`< 10`), цикл останавливается.
4. Пример: 39 → 27 → 14 → 4: три шага. Для однозначного входа шагов 0.

### Задача 5. `mse` — средняя квадратичная ошибка
```python
predicted, expected = data.predicted, data.expected
return sum((x - y) ** 2 for x, y in zip(predicted, expected)) / len(predicted)
```
1. `zip` идёт парами по элементам двух векторов без ручных индексов: `(x1,y1), (x2,y2), ...`.
2. Для каждой пары считаем квадрат разности и суммируем.
3. Делим на `n = len(predicted)` — это формула MSE = (1/n)·Σ(xᵢ−yᵢ)².
4. Корня здесь НЕТ сознательно: с корнем была бы уже RMSE (среднеквадратическое отклонение),
   а в README дана формула без корня.

### Задача 6. `prime_factorization` — разложение на простые множители
```python
parts, divisor = [], 2
while divisor * divisor <= number:      # перебор делителей до sqrt(number)
    if number % divisor == 0:
        power = 0
        while number % divisor == 0:    # «вычерпываем» все степени этого делителя
            number //= divisor
            power += 1
        parts.append(f"({divisor})" if power == 1 else f"({divisor}**{power})")
    divisor += 1
if number > 1:                          # оставшийся множитель — простой
    parts.append(f"({number})")
return "".join(parts)
```
1. Метод пробного деления: идём делителем вверх от 2.
2. Зачем достаточно до √n: если `n = a·b`, то хотя бы один из множителей не превосходит √n;
   значит, все составные делители уже «разобраны» меньшими простыми, и остаток > 1 может быть только простым.
3. Внутренний цикл считает степень: сколько раз число делится на делитель без остатка.
4. Степень 1 по условию не печатается: `(5)`, а не `(5**1)`.
5. Делители идут по возрастанию автоматически (цикл идёт снизу вверх). `n = 1` → пустая строка.
6. Сложность O(√n).

### Задача 7. `pyramid` — пирамида из кубиков
```python
total, k = 0, 0
while total < cube_count:   # наращиваем этажи, пока не догоним n
    k += 1
    total += k * k          # k-й этаж требует k² кубиков
return k if total == cube_count else "It is impossible"
```
1. Сумма квадратов `1²+2²+...+k²` строго растёт с k, поэтому достаточно одного прохода:
   набираем этажи, пока сумма меньше n.
2. Цикл остановился ровно на n — пирамида существует, возвращаем k (последний добавленный этаж).
3. Перескочили n — представить число в виде суммы квадратов подряд идущих этажей нельзя → строка
   `"It is impossible"`. Примеры: 5 = 1+4 → k=2; 10 проскакивает между 5 и 14 → невозможно.

### Задача 8. `is_balanced_number` — сбалансированное число
```python
number = data.value
digits = [int(ch) for ch in str(number)]   # список цифр
count = len(digits)
middle = count // 2
if count % 2:                              # цифр нечётное число
    left, right = digits[:middle], digits[middle + 1:]      # средняя цифра выбрасывается
else:                                      # цифр чётное число
    left, right = digits[:middle - 1], digits[middle + 1:]  # выбрасываются две средние
return sum(left) == sum(right)
```
1. Число переводим в строку и режем на цифры — так проще брать срезы.
2. Нечётный пример `1234006`: middle = 3, слева `123`, справа `006`, средняя `4` не учитывается;
   1+2+3 = 0+0+6 → `True`.
3. Чётный пример `123456`: middle = 3, слева `digits[:2] = 12`, справа `digits[4:] = 56`,
   две средние `3` и `4` выброшены; 1+2 ≠ 5+6 → `False`.
4. Ответ — сравнение сумм двух половин.

## Часть 2. numpy_tasks.py

### Задача 1. `sum_prod` — сумма произведений матриц на векторы
```python
matrices = np.asarray(matrices, dtype=float)
vectors = np.asarray(vectors, dtype=float)
if vectors.ndim == 1:            # один вектор (n,)
    vectors = vectors.reshape(1, -1, 1)
elif vectors.ndim == 2:          # набор векторов (p, n)
    vectors = vectors[:, :, np.newaxis]
return np.matmul(matrices, vectors).sum(axis=0)
```
1. `np.asarray` гарантирует, что вход — ndarray (а не список списков), и приводит тип к float.
2. Нормализуем форму векторов до `(p, n, 1)`: `np.newaxis` добавляет ось длиной 1;
   `-1` в reshape означает «подставить нужную длину сам».
3. `np.matmul` для трёхмерных массивов работает **пакетно**: перемножает пары
   `(n, n) @ (n, 1)` по первой оси → получаем `(p, n, 1)`, то есть все p произведений сразу, без цикла.
4. `.sum(axis=0)` складывает p векторов-результатов вдоль оси p → остаётся `(n, 1)`, как требует условие.

### Задача 2. `binarize` — бинаризация
```python
matrix, threshold = data.matrix, data.threshold
return (np.asarray(matrix) > threshold).astype(int)
```
1. `matrix > threshold` — **булева маска**: поэлементное сравнение даёт массив той же формы из True/False.
   Сравнение строгое: элемент, равный порогу, даёт False.
2. `.astype(int)` превращает True/False в 1/0.
3. И сравнение, и `astype` создают **новые** массивы, поэтому исходная матрица не изменяется
   (это отдельное требование условия).

### Задача 3. `unique_rows` / `unique_columns`
```python
return [np.unique(row).tolist() for row in np.asarray(matrix)]                 # строки
return [np.unique(matrix[:, column]).tolist() for column in range(matrix.shape[1])]  # столбцы
```
1. `np.unique(x)` убирает дубликаты и сортирует по возрастанию.
2. По строкам итерируемся напрямую: цикл по 2D-массиву отдаёт строки-срезы.
3. По столбцам берём срез `matrix[:, column]` — все строки, один столбец.
4. `.tolist()` превращает ndarray в обычный список: контракт требует `list[list[float]]`.

### Задача 4. `matrix_statistics` — статистики случайной матрицы
```python
generator = np.random.default_rng(seed)
matrix = generator.normal(loc=mean, scale=std, size=(rows, columns))
return MatrixStatistics(
    matrix=matrix,
    row_means=matrix.mean(axis=1),
    column_means=matrix.mean(axis=0),
    row_variances=matrix.var(axis=1),
    column_variances=matrix.var(axis=0),
)
```
1. `np.random.default_rng(seed)` — современный генератор (Generator/PCG64): при одном и том же seed
   последовательность случайных чисел воспроизводима, что и нужно грейду.
2. `.normal(loc, scale, size)` — выборка из нормального распределения со средним `mean`
   и стандартным отклонением `std`, форма `(rows, columns)`.
3. `axis=1` «схлопывает» ось столбцов → остаётся по значению на строку; `axis=0` наоборот —
   по значению на столбец. То есть `mean(axis=1)` — средние по строкам, `var(axis=0)` — дисперсии столбцов.
4. Результат упаковывается в контейнер `MatrixStatistics` из `grader_contracts`.

### Задача 5. `chess` — шахматная матрица
```python
board = np.full((rows, columns), first, dtype=np.result_type(first, second))
row_index, column_index = np.indices((rows, columns))
board[(row_index + column_index) % 2 == 1] = second
return board
```
1. `np.full` создаёт матрицу, целиком залитую значением `first` (левый верхний угол гарантированно `first`).
2. `np.result_type` подбирает общий тип: для целых a, b матрица целая, для вещественных — float.
3. `np.indices` возвращает две матрицы той же формы: в одной номер строки каждой клетки, в другой номер столбца.
4. Чётность `i + j` чередуется по горизонтали и вертикали ровно как на шахматной доске,
   поэтому маска `(i + j) % 2 == 1` отмечает «чёрные» клетки; булева индексация присваивает им `second`.

### Задача 6a. `draw_rectangle` — прямоугольник в центре
```python
image = np.empty((image_height, image_width, 3), dtype=np.uint8)
image[:, :] = np.asarray(background_color, dtype=np.uint8)
width, height = min(width, image_width), min(height, image_height)
top = (image_height - height) // 2
left = (image_width - width) // 2
image[top:top + height, left:left + width] = np.asarray(shape_color, dtype=np.uint8)
```
1. Изображение — трёхмерный массив `(H, W, 3)`: высота, ширина, три RGB-канала; `uint8` —
   стандартный тип пикселя (1 байт на канал, значения 0–255).
2. `image[:, :] = фон` красит все пиксели фоновым цветом (тройка транслируется на все пиксели).
3. `min(...)` защищает от прямоугольника больше картинки.
4. Целочисленное деление на 2 даёт отступы сверху/слева — так прямоугольник оказывается в центре.
5. Присваивание срезу `image[строки, столбцы] = цвет` закрашивает всю область за одну операцию, без циклов.

### Задача 6b. `draw_ellipse` — эллипс в центре
```python
image[:, :] = фон
x0 = (image_width - 1) / 2          # центр изображения
y0 = (image_height - 1) / 2
y_coordinates, x_coordinates = np.ogrid[:image_height, :image_width]
inside = ((x_coordinates - x0) ** 2 / semi_axis_x ** 2
          + (y_coordinates - y0) ** 2 / semi_axis_y ** 2) <= 1
image[inside] = np.asarray(shape_color, dtype=np.uint8)
```
1. `np.ogrid` — «разреженная» сетка координат: столбец y формы `(H, 1)` и строка x формы `(1, W)`.
   Дальше работает **broadcasting**: при арифметике они автоматически растягиваются до полной матрицы `(H, W)`,
   не allocating лишнюю память (в отличие от `mgrid`).
2. Формула из условия: точка внутри эллипса, если `(x−x0)²/a² + (y−y0)²/b² ≤ 1`;
   выражение считается сразу для всех пикселей → булева маска `inside`.
3. Центр берём `(W−1)/2, (H−1)/2` — это геометрический центр сетки пикселей, поэтому фигура симметрична.
4. `image[inside] = цвет` — присваивание по булевой маске: красятся только пиксели с True.

### Задача 7. `analyze_time_series` — анализ временного ряда
```python
values = np.asarray(values, dtype=float)
previous, current, following = values[:-2], values[1:-1], values[2:]
local_maxima_indices = np.nonzero((current > previous) & (current > following))[0] + 1
local_minima_indices = np.nonzero((current < previous) & (current < following))[0] + 1
kernel = np.ones(window) / window
moving_average = np.convolve(values, kernel, mode="valid")
```
1. Три сдвинутых среза выравнивают соседей: i-й элемент `current` — это элемент № i+1 исходного ряда,
   `previous[i]` и `following[i]` — его левый и правый соседи. Сравнения поэлементные, без цикла.
2. `(current > previous) & (current > following)` — маска строгих локальных максимумов
   (поэтому плато вроде `5, 5` максимумом не считается); `np.nonzero(...)[0]` даёт позиции в срезе,
   а `+ 1` возвращает их к индексам исходного ряда (срез сдвинут на один элемент).
3. Первый и последний элементы в срезы не попадают — они экстремумами не считаются, как требует условие.
4. Скользящее среднее — свёртка с ядром из p одинаковых весов `1/p`: `np.convolve(..., mode="valid")`
   выдаёт результат только там, где окно целиком лежит внутри ряда, то есть ровно `n − p + 1` значений.
5. Среднее/дисперсия/СКО — `mean()`, `var()`, `std()` по всему ряду; всё упаковывается в `TimeSeriesStatistics`.

### Задача 8. `one_hot` — one-hot encoding
```python
labels = np.asarray(labels, dtype=int).ravel()
if class_count is None:
    class_count = int(labels.max()) + 1 if labels.size else 0
encoded = np.zeros((labels.size, class_count), dtype=int)
valid = (labels >= 0) & (labels < class_count)
encoded[np.arange(labels.size)[valid], labels[valid]] = 1
```
1. Метки приводим к целым и к одномерному виду (`ravel`).
2. Если число классов не задано, столбцов должно быть `max(метка) + 1` (классы нумеруются с нуля);
   для пустого входа — 0 столбцов.
3. Заготовка — нулевая матрица `(n, class_count)`.
4. Хитрость — **fancy indexing парами индексов**: `np.arange(n)` — номера строк, `labels` — номера столбцов;
   присваивание `encoded[строки, столбцы] = 1` ставит единицу ровно в позицию своего класса за одну операцию.
5. Маска `valid` — защита: метка вне диапазона `[0, class_count)` не уронит программу IndexError.

## Вероятные вопросы на защите и короткие ответы

- **Почему в `mse` нет корня?** Условие задаёт MSE = (1/n)·Σ(x−y)²; корень дал бы RMSE — другую величину.
- **Зачем `zip` в `mse`, а не индексы?** `zip` даёт пары элементов без ручного счётчика — короче и без off-by-one.
- **Почему в разложении достаточно делителей до √n?** У составного числа `n = a·b` меньший множитель ≤ √n;
  не поделённый остаток после цикла может быть только простым.
- **Чем `default_rng(seed)` лучше `np.random.seed`?** Новый API Generator не трогает глобальное состояние,
  воспроизводим по seed и рекомендован NumPy; старый `np.random.*` — legacy.
- **Что значит `axis=1` у `mean`?** Ось, вдоль которой идёт редукция: `axis=1` схлопывает столбцы →
  по значению на строку; `axis=0` — наоборот.
- **Что такое broadcasting?** Автоматическое согласование форм: массивы `(H, 1)` и `(1, W)`
  в арифметике растягиваются до `(H, W)` без копирования данных.
- **`ogrid` против `mgrid`?** `ogrid` даёт разреженные векторы координат (экономит память),
  `mgrid` — полную сетку; результат выражений одинаковый благодаря broadcasting.
- **Почему `binarize` не портит исходную матрицу?** Операции сравнения и `astype` создают новые массивы,
  in-place изменений нет.
- **Зачем `uint8` в картинках?** Стандарт изображений: 1 байт на канал, диапазон 0–255, форма `(H, W, 3)`.
- **Почему в шахматке `(i + j) % 2`?** Чётность суммы координат чередуется и по строкам, и по столбцам —
  это и есть раскраска доски; соседние клетки всегда разной чётности.
- **Зачем `+ 1` индексам экстремумов?** Средний срез `values[1:-1]` сдвинут на единицу относительно ряда.
- **Почему плато не экстремум?** Условие требует строгих неравенств: элемент должен быть строго больше/меньше обоих соседей.
- **Что даёт `mode="valid"` в `convolve`?** Только положения, где окно длины p целиком внутри ряда → длина `n − p + 1`.
- **Как работает `encoded[строки, столбцы] = 1`?** Парная (fancy) индексация: каждому i ставится единица
  в клетку `(i, labels[i])` — вся one-hot матрица за одну операцию.
- **Почему `len(set(text)) == len(text)` проверяет уникальность?** Множество удаляет дубликаты:
  если длина не изменилась, повторов не было.
- **Сложности:** подсчёт гласных/уникальности/MSE/экстремумов — O(n); пробное деление — O(√n);
  пакетный `matmul` — O(p·n³) арифметики, но без Python-циклов (векторизовано в C).
- **Зачем `.tolist()` в задаче 3?** Контракт требует обычные списки `list[list[float]]`, а не ndarray.
- **Что такое frozen dataclass в `grader_contracts`?** Неизменяемый контейнер входных/выходных данных:
  поля нельзя переприсвоить, грейд получает предсказуемую структуру.
